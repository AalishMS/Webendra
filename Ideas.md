# Webendra Idea Registry

This file is both a prompt for generating new Webendra characters and the
canonical record of names that have already been used or suggested. Read the
entire registry before proposing anything new.

## Prompt for generating new ideas

```text
Suggest 5 strong new name-and-image combinations for Webendra, a gallery of
ordinary things given unnecessarily dignified names by adding “-endra.”

Before answering, read the full idea registry below. Do not repeat, rename, or
make a near-duplicate of any implemented or previously stated idea. Treat names
case-insensitively.

Each idea must:
- have a short, pronounceable name ending in -endra; mild phonetic cheating is
  welcome when it makes the name land better;
- pair the name with one familiar subject that is recognizable immediately;
- work as a clean, realistic, square studio image with a transparent background;
- contain no embedded text, logo, border, watermark, elaborate lore, caption,
  or secondary joke;
- favor a varied mix of people, animals, food, and objects;
- keep any weapon non-threatening, with no firing, ammunition, aggression, or
  weapon pointed toward the viewer.

Before showing the ideas to the user, append every idea you intend to show to
the “Previously stated / not currently implemented” table in this file. Save
the file first, then return exactly those saved ideas in this format:

| Name | Image concept |
| --- | --- |
| Exampleendra | One concise, visually specific image description. |

Every idea becomes permanently reserved as soon as it is suggested. Record it
whether the user accepts it, rejects it, ignores it, or never implements it. Do
not present an unsaved extra idea, alternate name, or bonus suggestion.
```

## How to maintain this registry

- Add every suggestion to the second table before presenting it to the user.
  Suggestions are recorded regardless of whether they are accepted, rejected,
  ignored, or implemented later.
- Move an entry to the implemented table when it is added to `characters` in
  `catalogue.js`; include its final asset path.
- If an implemented character is removed, move it back to the second table.
- Never delete a rejected or unused idea. It remains reserved so it cannot be
  suggested again.
- Keep one row per character and sort new batches alphabetically within their
  status section.
- Search this entire file case-insensitively before adding a name or a visually
  equivalent subject.
